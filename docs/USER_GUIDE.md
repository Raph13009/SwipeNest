# SwipeNest AI — User guide

## First launch

1. Open the app (default: http://localhost:3000).
2. Choose **Start swiping** for personal onboarding, or **Try demo profile** for Camille’s Paris preferences.
3. Complete budget, arrondissements, amenities and optional dream description.

## Discover

- Swipe right / tap the heart to like.
- Swipe left / tap X to reject.
- After a reject, optionally pick a reason — this updates future ranking.
- Tap **Why this apartment?** for explainable match factors.
- Undo reverses the last swipe.

## Taste DNA

Open **Taste DNA** to see learned affinities for light, size, style, neighborhoods and amenities. Values update from real interactions. Use **Reset DNA** to clear learned signals while keeping stated preferences.

## Dream search

Type natural language such as “Bright Haussmannian under €1,500”. Refine with follow-ups like “something bigger”.

## Saved & compare

Liked apartments appear in **Saved**. Select 2–3 and run comparison for trade-offs based on your priorities.

## Map

Explore Paris markers colored by risk. Open a popup for details.

## Apply with AI

From a listing page, generate a French or English landlord message, switch tone, edit, and copy. Nothing is sent automatically.

## Settings

- Switch English / French
- Edit budget and profile fields used in drafts
- Observe live recommendation adaptation weights
- Reset demo data
